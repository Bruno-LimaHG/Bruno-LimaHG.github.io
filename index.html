Projeto Carro-Chefe

SIGACRC — Gestão Digital para Cartórios de Registro Civil

Um sistema corporativo completo para modernização e desburocratização de habilitações de casamento civil via internet, com foco em segurança documental e conformidade legal.

SIGACRC — Sistema Integrado de Gestão

Eliminação de filas físicas, triagem inteligente de pedidos e tramitação digital segura de certidões.

Node.js Express REST API MongoDB & Mongoose AWS S3 (Pre-Signed) Redis & BullMQ WebSocket / Socket.io JWT Stateless Jest & Supertest LGPD Compliant
Ver Repositório no GitHub

O SIGACRC nasceu para responder a um desafio real do setor público e cartorário: o atendimento presencial moroso e burocrático para casamentos civis. Através de uma plataforma unificada, requerentes realizam o cadastro de ponta a ponta na web, enquanto escreventes e oficiais analisam documentos, validam certidões e despacham pendências com total rastreabilidade.

AWS S3 Pre-Signed URLs

Certidões e dados sigilosos nunca são expostos publicamente. O backend gera URLs temporárias pré-assinadas com tempo de expiração controlado para os escreventes.

Filas Assíncronas (BullMQ)

Notificações transacionais, processamento de e-mails e compressão de arquivos são gerenciados por workers desacoplados via Redis, mantendo a API ultra rápida.

Chat em Tempo Real

Módulo de "Atendimentos" integrado com Socket.io, permitindo que noivos tirem dúvidas e recebam orientações dos funcionários sem deslocamento físico.

Conformidade com a LGPD

Implementação de controles estritos de privacidade, autorização baseada em cargos (RBAC), logs de auditoria e documento formal de Política de Privacidade LGPD.

Queues & DB
  • Autenticação Segura: Cadastro e login dos noivos protegidos por token JWT stateless via cabeçalho HTTP Authorization: Bearer.
  • Preenchimento Guiado em Etapas: Interface em wizard com validação de campos obrigatórios, regime de bens e dados dos cônjuges.
  • Consulta Automatizada de CEP: Integração assíncrona com ViaCEP para autopreenchimento imediato de logradouros, bairros e cidades.
  • Upload Digital de Certidões: Envio de comprovantes e documentos civis diretamente para a nuvem da AWS sem expor servidores.
  • Painel Administrativo: Acesso restrito a escreventes e oficiais com controle de permissão baseado em papéis (RBAC).
  • Trâmite de Status em Tempo Real: Gestão de estados do pedido (Em Análise, Exigência Documental, Aprovado, Recusado).
  • Visualizador Seguro de Documentos: Geração instantânea de links temporários (Pre-Signed) para visualização confidencial dos anexos.
  • Sistema de Atendimentos: Histórico de conversas e mensagens com os noivos diretamente na plataforma.
  • Defesa contra Ataques: Rate limiting com express-rate-limit contra brute force e cabeçalhos HTTP fortalecidos via Helmet.
  • Logging Estruturado: Rastreamento ponta a ponta com Winston e Morgan para auditoria forense e monitoramento.
  • Suíte de Testes Automatizados: Testes de integração e rotas executados via Jest e Supertest.
  • Rotina de Backup Automatizada: Scripts integrados para exportação preventiva de coleções do MongoDB.
